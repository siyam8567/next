# Birthday / Love Card Site

A small static website. Open `index.html` in a browser, or view it live on GitHub Pages.

## Structure
- `index.html`: the page
- `style.css`: styles
- `images/`: decorations and artwork

## Publish on GitHub Pages
1. Create a new repository on GitHub (e.g. `final`).
2. Upload everything in this folder to the repository root (keep `index.html` at the top level).
3. Go to **Settings → Pages**, set **Source** to `Deploy from a branch`, choose `main` and `/ (root)`, then Save.
4. After about a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
